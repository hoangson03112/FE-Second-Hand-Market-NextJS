# 🛒 Second-Hand Market - EcoMarket (Next.js)

## 📖 Overview
The frontend repository for the Second-Hand Market platform. Built with Next.js, this application provides a blazing-fast, SEO-friendly, and highly responsive user interface for buyers and sellers to connect, browse, and trade pre-owned items seamlessly.

## 🚀 Key Features
* **Modern UI/UX:** Responsive design optimized for both desktop and mobile devices.
* **Authentication:** Secure user login and registration flows.
* **Product Discovery:** Advanced search, filtering, and pagination for second-hand items.
* **Shopping Cart & Checkout:** Streamlined flow for managing selected items and processing orders.
* **User Dashboard:** Order history, profile management, and item listing management for sellers.

## 💻 Tech Stack
* **Framework:** Next.js
* **Styling:** Tailwind CSS / CSS Modules
* **State Management:** Zustand 
* **Language:** TypeScript 
* **Data Fetching:** React Query
